The agent: built for low time and space cost

1 Probe→2 Trim→3 Cheap LLM→4 Independent verifier→5 Grounding check→6 Human queue
1 Deterministic probes first
Try /openapi.json, llms.txt, the MCP registry. securitySchemes gives auth with zero LLM tokens. Cost O(|spec|).
2 Keyword-window trimming
Pages shrink to ±300 chars around auth, pricing and approval terms, so tokens per page are constant (≤6k chars) and ≤3 pages per app. Total work O(N·K), not O(N·page size).
3–4 Two models, different roles
A small model extracts; a larger model answers independently. Disagreement raises a flag.
5 Evidence-bound cells
Every answer carries a verbatim quote. A string match against the fetched page rejects invented evidence.
Concurrency and space
Semaphore-bounded async (C=12), so wall time ≈ N/C × latency. A disk cache keyed by URL hash makes reruns idempotent; output streams to JSONL, so memory is O(N).
6 Humans only on flags
People review disagreements, ungrounded quotes and a stratified sample, not all 100. Composio SDK/MCP slots in as the fetch and search layer.

Design estimate, not measured: about 100×3×1.5k ≈ 0.45M input tokens for the extraction pass. Limit: the script was not run end-to-end against live docs here, so the table is a first pass from prior knowledge, not the agent's output.

Verification (honest)

Protocol: loop 1 = quote grounding + model disagreement; loop 2 = web or browser re-check of flagged rows; loop 3 = human check of a stratified sample (≥2 per category, over-sampling amber and red). Accuracy is reported per field: auth, gate, MCP, verdict.

Checked so far: Otter AI. The table says OAuth, vendor-hosted MCP, REST gated. A web check found the MCP at mcp.otter.ai/mcp with OAuth and 3 tools, while the public REST API is beta and Enterprise-only. Match. The MCP door is open while the REST door is gated.

Not yet measured: the other 99 rows, so no first-pass to final accuracy figure is claimed. Riskiest cells: fanbasis, Paygent, iPayX, Waterfall.io, Consensus, higgsfield (thin or no public docs) and every MCP cell, since that changes fast.
